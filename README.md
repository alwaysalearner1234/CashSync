# CashSync – Smart Conversation to Cash Platform

**CashSync** is a premium fintech application that turns business conversations into instant revenue using AI-powered invoicing and smart reminders.

## 🚀 Features

- **AI Invoice Generation**: Simply paste your business messages (e.g., "3 logos for ₹5000 each") and let AI extract the details.
- **Premium Dashboard**: A high-fidelity, animated interface with real-time stats and glassmorphic design.
- **Smart Reminders**: Automated follow-up system with friendly, reminder, and urgent tones.
- **Instant Payments**: Seamless integration with payment gateways (Razorpay).
- **Responsive Design**: Fully optimized for mobile and desktop with smooth animations.

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS v4, Framer Motion, Lucide React.
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB (with in-memory fallback).
- **AI**: Google Gemini AI.

## 📦 Installation

### Prerequisites
- Node.js (v18+)
- MongoDB (optional, fallback to in-memory)
- Gemini API Key

### Setup

1. **Clone the repository**:
   ```bash
   git clone git@github.com:alwaysalearner1234/CashSync.git
   cd CashSync
   ```

2. **Backend Setup**:
   ```bash
   cd server
   npm install
   cp .env.example .env # Update your API keys
   node index.js
   ```

3. **Frontend Setup**:
   ```bash
   cd client
   npm install
   npm run dev
   ```

## 🎨 Design Vision

Inspired by Stripe and Notion, CashSync uses a "Fintech OS" aesthetic with dark mode, glassmorphism, and vibrant gradients.
